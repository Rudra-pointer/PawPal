# PawPal five-minute demo

1. **Welcome (25 sec):** Open Home and point out the live featured pets and the adoption-first design.
2. **Discover (55 sec):** Browse pets, search by name or breed, adjust species/location/availability filters, and open a pet profile. Show health details, good-with assessments, photos, and bonded-pair information.
3. **Match (40 sec):** Complete the seven-question quiz and review ranked matches and compatible pairs.
4. **Apply (55 sec):** Sign in as an adopter, save a pet, submit an application, and show the application timeline in the adopter dashboard.
5. **Shelter workflow (70 sec):** Sign in as a verified shelter, review the application, update the required checks, approve it, and complete the adoption.
6. **Admin and close (55 sec):** Show shelter verification, listing/report moderation, and the audit feed. Explain that access control and ownership checks are enforced by the API as well as the UI.

Use the local demo accounts documented in `README.md` and the configured `SEED_PASSWORD`. Keep the demo database separate from production data.
