# PawPal demo animal photo credits

These are separate, source photographs selected for fictional demo profiles. The source files are downloaded from the specified photo pages and converted to WebP with Sharp at a maximum 1600 px long edge. Conversion/resizing and metadata removal are the only image changes; no captions, borders or watermarks were added. No genuine shelter-submitted photos were replaced.

Pexels photos use the [Pexels License](https://www.pexels.com/license/); attribution is not required by that license, but is provided here. ## Not integrated: Sneaker Singh

The supplied [Pexels page 8240127](https://www.pexels.com/photo/a-person-holding-a-puppy-8240127/) returned no readable page metadata and an HTTP access error during source verification. The direct Pexels CDN image was downloadable and visually shows a puppy with a person, but the page photographer could not be independently confirmed. To avoid publishing an image without reliable source attribution, it was not copied into the project, converted into a demo asset, or attached to a pet profile. Its temporary inspection copy was 5472 × 3648. No substitute was used.
